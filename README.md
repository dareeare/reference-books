#Разработка модуля справочной информации бизнес-приложения

## Справочник «Преподаватели» 
| Колонка | Тип данных | Описание |
|---------|------------|----------|
| ID преподавателя | Целое число (PK) | Уникальный идентификатор |
| ФИО | Текст | Полное имя преподавателя |
| Специализация | Текст | Область знаний (например, "Программирование") |
| Дата трудоустройства | Дата | Когда принят на работу |
| Ставка за час | Число с фиксированной запятой | Оплата за 1 час занятий (BYN) |
| Количество курсов | Целое число | Сколько курсов ведёт |

## Справочник «Курсы обучения» 
| Колонка | Тип данных | Описание |
|---------|------------|----------|
| ID курса | Целое число (PK) | Уникальный идентификатор |
| Название курса | Текст | Наименование курса |
| Преподаватель | **Ссылка (FK)** | Ссылка на ID преподавателя |
| Дата старта | Дата | Первый день занятий |
| Стоимость курса | Число с фиксированной запятой | Цена за весь курс (BYN) |
| Количество часов | Целое число | Общая длительность в часах |
